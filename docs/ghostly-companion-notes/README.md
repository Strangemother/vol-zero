# Ghostly Companion Notes

A durable, repo-local workspace for the AI collaborator working with Jay on VOL Zero and the earlier Virtual Operating Layer (VOL).

**Purpose:** restore useful working context across conversations, track ongoing investigations, and make architectural reasoning reviewable. These notes are *not* a substitute for Jay's decisions, the source code, or the original research.

## Where to begin

1. [Context and working agreement](context.md) — project map, conventions, and collaboration boundaries.
2. [Architecture map](architecture-map.md) — provisional correspondence between historic VOL and VOL Zero.
3. [Open questions and work queue](work-queue.md) — what to investigate next.
4. [Session log](session-log.md) — dated decisions, findings, and links.

## Working rules

- Preserve original historical material in [Virtual-Operating-Layer](https://github.com/Strangemother/Virtual-Operating-Layer/tree/primary/docs). Treat AI-authored interpretations as secondary sources.
- Distinguish **verified implementation**, **original proposal**, **hypothesis**, **open question**, and **decision by Jay**.
- Cite source paths, commit or revision references when possible; never silently promote a speculative idea to a specification.
- Before changing architecture, inspect current code and discuss design choices with Jay. Prefer small branches and reviewed pull requests; don't deploy automatically without agreement.
- Update these files when a session produces durable findings. Do not store secrets, credentials, personal details, or ephemeral chat transcripts.
- Notes can be stale; verify against current code before relying on them.

Created 2026-10-19 as an initial scaffold. No architecture decisions are made by this addition.
