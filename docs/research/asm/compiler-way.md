This file describes the syntax rules and conventions for the assembly code generated by the compiler.

## Overview

The compiler can be considered a simple "asm emitter" that translates high-level code into assembly instructions through linear conversion of the given code into literal assembly representations.

It's designed to initially simplify the readability of the raw assembly code. For example:

```py
reg.eax = 1
reg.eax += 2
```

```asm
mov eax, 1
add eax, 2
```

Further abstraction allows literal assembly into higher-level constructs, running python code in parrallel to the 'compiler' to dynamically generate and manipulate assembly instructions. For example

```py
def add_some(*values):
    for value in values:
        reg.eax += value

def generate_asm():
    reg.eax = 1
    reg.eax += 2

clear()
generate_asm()  
add_some(3, 5)
```

## Components

The compiler reads high-level and _emits_ literal assembly instructions. This provides a COMPILE-TIME and RUNTIME understanding of the code. 

### Registry Module

The Registry module provides an interface for generating literal assembly instructions. 

It allows direct manipulation of CPU registers and memory locations through a Pythonic syntax, which is then translated into actual assembly code by the compiler.

```py
reg.eax = 1
reg.eax.add(2)
reg.eax + reg.ebx
```

Typically this is a found as an Registry module, however objects may return prepared asm modules:

```py
reg = Registry('x32')
reg.eax = 1
```

### Assignment

The ASM module essentially supports all instructions.
Each instruction is a literal, and can be directly manipulated or combined with other instructions to form complex assembly sequences.

```py
reg.eax = 1
reg.eax.add(2)
reg.eax + reg.ebx
reg.eax.move(reg.ebx)
```

### Raw  

Emit raw assembly instructions directly using the ASM module's `raw` method.

```py
asm.raw("mov eax, 1")
asm.raw("add eax, 2")
```

### Arithmetic Operations

Arithmetic operations can be performed directly on the ASM module's registers. These operations are translated into the corresponding assembly instructions.

```py
# overloaded py
reg.eax = 1
reg.ebx += 2

# functional 
reg.eax.add(reg.ebx)
reg.eax.sub(1)
reg.eax.mul(reg.ebx)
reg.eax.div(2)
```

## Compile time Module

We can reference the environment at compile-time, if meta programming of the asm literals;

```py
if COMPILER.arg('alt-step'):
    reg.eax += 1
    asm.ah += 1
else:
    reg.eax = 2
```

The emitted assembly code only sees one branch:

```bash
$ python compile.py --alt-step=1
``` 

```asm
add eax, 1
add ah, 1
```
