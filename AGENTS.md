# Project Notes

- This is a kernel project built on Limine and Nim.
- The project aims to create a minimalistic and efficient operating system kernel: VOL 
- The Virtual Operating Layer is a new style of operating system architecture built for a graph based structure.


## Code Conventions


The language used for this project is Nim, HOWEVER, the VOL has its own unique structure and design principles.
The code follows a set of conventions to ensure readability and maintainability befitting the VOL kernel.

- Graph-based structures are preferred for representing system components.
- Comments should be used to explain complex logic and design decisions.

## Naming Conventions

- 4 spaces indentation should be used for code blocks and nested structures.
- lower_snake_case should be used for variable and function names.
- Use consistent naming patterns for similar types of entities.
- UpperCamelCase should be used for type names.


## Assistance and Code input

- When seeking assistance or input for code, be aware that the VOL kernel has unique design principles and conventions.
- When unsure, aim for less code changes and lean on teaching. This content typically will involve low level system programming.
- The developer prefers learning, unless coding input is requested.

## Tools 

Primary tools are Nim compiler, Limine bootloader, and standard development utilities like Git and Make.

The `tool` utility is the main interface for interacting with the VOL kernel's build and development processes for the developer.
